# Чеки и бюджет (Receipts & Budget)

Нативное Android-приложение для учёта личных расходов и семейного бюджета с автоматическим сканированием QR-кодов российских кассовых чеков.

## Основные возможности
* **Сканер QR-кодов ФНС:** распознавание суммы, даты и фискальных признаков (`fn`, `fd`, `fp`) через камеру с использованием ZXing.
* **Защита от дубликатов:** проверка уникальности чека по фискальному ключу.
* **Умная категоризация:** автоматическое определение категории по названию магазина (Продукты, Аптека, Автомобиль, Транспорт, Одежда, Обучение, Дом, Развлечения).
* **Разделение чека:** возможность разбить один чек на несколько категорий с контролем остатка до копейки.
* **Аналитика и экспорт:** статистика трат за текущий месяц с визуализацией долей и выгрузка отчёта в `.txt`.

## Стек технологий
* **Язык:** Java (Android SDK 21–35)
* **База данных:** SQLite (`SQLiteOpenHelper`)
* **Сканирование штрихкодов:** ZXing (`com.google.zxing`)
